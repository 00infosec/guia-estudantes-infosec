# Código de conduta

Este projeto busca oferecer um ambiente respeitoso e acolhedor para estudantes de diferentes níveis e origens.

Discussões e revisões técnicas devem ser construtivas. Não são aceitos assédio, discriminação, intimidação, exposição de dados pessoais, incentivo a acesso não autorizado ou ridicularização de dúvidas de iniciantes.

A equipe poderá moderar contribuições e restringir a participação quando necessário para proteger a comunidade.
